# 新数据源适配指南

数据源是可替换模块。新增来源时应实现 `SourceAdapter.collect()`，返回：

- `articles`：标准化文章记录；
- `health`：来源运行状态与接受/拒绝数量；
- `warnings`：可审计的错误，不得静默吞掉。

合并前必须满足：

1. 只采集合法公开数据或用户有权访问的数据；
2. 不绕过登录、验证码、访问控制或反爬限制；
3. 不要求安装根证书或截取微信私人凭据；
4. 明确区分“文章发现”与“互动指标证据”；
5. 为解析器增加固定测试样本，页面结构变化时应失败而不是误读。

发现适配器可以只返回文章身份信息，但不得填充或推测转发、点赞。指标适配器必须为每项指标提供原始显示值、证据 URL 和观察时间。
